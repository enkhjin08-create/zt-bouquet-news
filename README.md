# Сонин баглаа (zt-bouquet-news)

- `/` — захиалагч загвараа сонгож, зураг, үгээ оруулаад илгээнэ
- `/admin.html` — захиалгууд, засах, A3 хэвлэх (нууц үг: Netlify дээрх `ADMIN_PASS`)

Загварууд: Захидал сонин, Хар цагаан сонин, Ягаан polaroid, Ордын сонин.
Сонины нэрний фонт: Santa Catarina (`public/fonts`, Ө Ү үсгийг нэмж хийсэн).

## Байршуулалт

`main` салбар руу push хийх бүрт Netlify автоматаар шинэчилнэ.

## Хэвлэх

Админ дээр «A3 хэвлэх» → хэвлэх цонхонд Paper size **A3**, Margins **None**, **Background graphics** ✓.
